# PrintSeamGroove：接縫集中槽刀具

版本：2026-09-05 待安裝預覽版。這是 R3dP Tools 的新增指令；原有 PrintSupport、PrintGear、PrintThread 保留。套件沿用既有外掛 ID，未寫入 Rhino 外掛目錄或註冊表。

## 用途與幾何定義

沿一條連續曲線產生等腰三角形截面的封閉 Brep，作為 BooleanDifference 的切削工具。曲線可以是直線、圓弧、NURBS、PolyCurve，或數條可接成單一路徑的曲線／Brep 邊緣。開放及封閉路徑均可。

**選取曲線代表溝槽開口中心線，不是槽底尖端線。** 請先把線放在預計開槽的構件表面。預設流程再選取參考面，以路徑切線與面法線共同決定截面方向；也可按 Enter 跳過選面，手動指定方向。

貼面模式：令路徑單位切線為 T，面外法線為 N。三角尖端方向取 −N（去除微小切線分量並正規化），截面寬度方向取 T × (−N)。三角形所在平面垂直於路徑切線，尖端沿局部面的反法線切入。每個截面都重新依當地法線定位，所以即使路徑是直線，參考面沿線扭轉時截面也能跟著轉。

槽底尖端與曲線相距「槽深」。在曲線所在的局部切平面位置，兩斜面的間距是「槽口寬度」。開放曲面沒有可靠的材料內外語意，請看預覽並用「尖端翻向」選正確側；完整、朝外定向的封閉 Brep 通常預設即為朝內。

為使刀具確實穿出構件，三角形背面會向表面外延伸。兩斜面沿原角度繼續延伸，因此背面比槽口寬；不會改變所設定的槽口寬度和槽深。

- W = 槽口寬度；D = 槽深；E = 外側延伸。
- 尖端相對中心線：+D，朝切入方向。
- 三角形背面相對中心線：−E，朝外側。
- 背面全寬：W × (D + E) / D。
- 尖端夾角：2 × atan(W / (2D))。
- W=0.6、D=0.3、E=0.2 mm 時：尖角 90°，刀具總高 0.5 mm，背面寬 1.0 mm；切入平面構件的槽仍寬 0.6、深 0.3 mm。

上述槽口尺寸以構件局部表面與設定截面方向匹配為前提；若曲線離開表面、表面彎曲或切入方向傾斜，實際交線尺寸會不同。

## 操作流程

1. 準備位於預計槽口位置的路徑，可畫線、抽取曲線或選取構件邊緣。
2. 執行 `PrintSeamGroove`，選取路徑，按 Enter。選多條時會嘗試依文件容差 Join 成一條，不會修改原始曲線。不能相接或分岔的路徑需分次執行。
3. 選取要開槽的參考面，可用 Ctrl+Shift 選 Brep 子面，也可多選相鄰面或完整 Brep，按 Enter。程式在取樣點選擇覆蓋路徑的有效修剪面。直接按 Enter 跳過選面時，才會要求以路徑起點為基準，點向材料內部指定手動方向。
4. 檢查橘色刀具預覽，可調整尺寸或翻向。貼面模式依各處法線定向；手動模式另可旋轉截面，旋轉角度是繞起點正向切線的角度，沿線依掃掠框架傳遞。
5. 按 Enter 建立。Esc 取消不新增模型物件。無有效實體時不允許確認，仍可改參數重試。
6. 執行 `BooleanDifference`，先選要開槽的構件，按 Enter，再選橘色刀具，按 Enter。新指令只生成刀具，沒有自動對構件執行差集。
7. 切片時查看 seam 標記；必要時使用 seam painting 指定到槽內。CAD 溝槽不會保證切片器自動選中該位置。

## 參數

| 中文選項 | 英文選項 | 首次預設（mm） | 說明 |
| --- | --- | ---: | --- |
| 槽口寬度 | Width | 0.6 | 路徑位置的開口寬度 |
| 槽深 | Depth | 0.3 | 路徑到尖端的距離 |
| 外側延伸 | Overcut | 0.2 | 刀具向構件外伸出的高度，協助形成穿越表面的交疊 |
| 端部延長 | EndExtension | 0 | 僅手動模式：開放路徑兩端各沿切線延長此距離 |
| 截面旋轉角度 | Rotation | 0° | 僅手動模式：繞起點切線旋轉截面 |
| 尖端翻向 | Flip | — | 把尖端方向反轉 |

尺寸使用目前文件單位；預設毫米值會換算到目前單位。成功建立後記住尺寸，跨文件仍按毫米換算；方向及旋轉每次重新指定。以上是可調建模起始值，未做實際列印校正。

W、D、E 都須大於文件絕對容差的四倍。過粗的容差會讓小槽無法建立；程式不會修改文件容差。端部延長不能小於零。

## 支援範圍與限制

- 貼面模式沿路徑自適應取樣面法線，以多截面掃掠生成刀具。最低 33 個含端點取樣站，依方向變化細分，最多約 512 個；閉合路徑避免重複放置終點截面。取樣區間的端點方向差控制在 4°，中點法線與兩端平均方向偏差控制在 0.5°。這是數值近似，未承諾所有中間點的全域誤差上限。
- 取樣點離參考面須不超過文件容差兩倍，而且要在修剪面有效範圍內；切線與面切平面偏差不超過 5°。不自動 Pull／Project，不跨越修剪孔洞去延伸底層曲面。採樣仍可能漏掉極小的局部缺口，請檢查模型與預覽。
- 貼面模式支援切線連續的 PolyCurve 及法線連續的相鄰面；路徑銳角或相鄰面法線突變時拒絕生成，請分段或圓角化。完整 Brep 邊上若同時有不同方向的候選面，可只選真正要開槽的那一面。
- 手動模式：平面彎曲路徑使用固定平面法線框架，空間路徑使用自由框架；不追隨表面法線。多段路徑的轉角採修剪接合。
- 掃掠、接合、封蓋失敗時不輸出零碎或開放物件。
- 閉合路徑建立環狀刀具；若閉合接點扭轉而無法形成有效實體，會拒絕輸出。
- 拒絕路徑自交／重疊；結果檢查有效性、封閉性、流形性、正體積，再以容差控制的網格檢查刀具自交。網格檢查是近似檢查，不是對任意曲面的數學保證。
- 截面過大、回折距離過小或尖銳轉角可能無法形成實體。請縮小尺寸、放緩轉角或分開處理。
- 開放路徑預設止於端點。手動模式可增加端部延長；貼面模式需自行把路徑延長到參考面有效範圍內，不會在沒有面法線的區域推測方向。
- 輸出為封閉 Brep，未保證 Rhino 一定把它標示成多重曲面而非單一特殊曲面；不輸出 Mesh 刀具。
- 物件名稱為 `PrintSeamGroove_Cutter`，橘色，建立在目前圖層。User Text 保存尺寸、文件單位、容差、來源物件 ID、定向模式及參考面／手動方向；來源曲線和面後續變更不會自動更新刀具。

## 驗證

已使用本機 Rhino 8 隱藏幾何核心執行自動檢查，沒有載入或安裝這個外掛至使用者 Rhino：

- 直線、圓弧、折線轉角、封閉圓、封閉矩形、空間樣條、直線＋圓弧 PolyCurve：生成有效封閉刀具，並成功執行實際 BooleanDifference。
- 直線案例比較理論槽體積與實際扣除體積，確認槽寬、槽深及外側延伸的尺寸定義。
- 反向路徑、垂直路徑、翻向、90° 旋轉、端部延長、亂序線段接合及英寸等效尺寸。
- 貼面模式：平面及封閉圓柱差集、扭曲曲面配直線路徑的尖端位置與翻向、跨相鄰面的平滑 PolyCurve、反向曲面法線。以未重合於截面取樣站的測試點比對生成尖端與目標法線位置。
- 斷開路徑、自交路徑、無效數值、平行方向及過小迴圈刀具自交拒絕。
- 貼面模式另測試離面、修剪孔洞及歧義銳角參考面的拒絕。
- 範例檔建立及回讀檢查。

精確案例數以套件內 `checks.txt` 為準。這些檢查驗證幾何核心；**尚未在 Rhino 使用者介面人工驗證選取、互動預覽與取消，也尚未試印。**

`SeamGroove-Examples.3dm` 可直接開啟檢查，不需安裝外掛。`01_Cutters` 為刀具，`02_BooleanResults` 為已開槽方塊與最後一組開放參考面；兩者位置重疊以便對照，可關閉刀具圖層檢查槽。物件名稱記錄各測試曲線類型，各組沿 Y 軸分開排列。手動空間樣條案例僅測試與平面方塊相交的區域，不代表整條空間曲線都會自動貼合方塊。最後一組 `SurfaceNormal_Twisting` 展示貼面模式如何沿扭曲面改變截面方向，其參考面是開放面，尚未進行差集。

## 建置與重跑

需 .NET 8 SDK 與已授權的 Rhino 8。標準環境：

```powershell
dotnet build .\PrintGear\PrintGear.csproj -c Release
dotnet build .\tests\SeamGrooveChecks -c Release
dotnet .\tests\SeamGrooveChecks\bin\Release\net8.0-windows\SeamGrooveChecks.dll
```

此工作區另有 `artifacts/toolchain/dotnet/dotnet.exe` 可用；若 Windows SDK 探測受權限限制，可傳入 `-p:TargetPlatformDisplayName=Windows`。測試只啟動隱藏核心並寫入 `artifacts/seam-groove-checks`，不執行外掛安裝。測試核心位置可用 `RHINO_SYSTEM_DIR` 指定。

掃掠使用 Rhino 8 已提供的 API，參考：[McNeel Brep.CreateFromSweep](https://developer.rhino3d.com/api/rhinocommon/rhino.geometry.brep/createfromsweep)。
