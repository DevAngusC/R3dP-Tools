# R3dP Tools

R3dP Tools 是供 Rhino 8 使用的 3D 列印建模工具，透過命令列建立支撐、齒輪、螺紋、Gridfinity 底座與接縫溝槽刀具。

| 指令 | 功能 | 輸出 |
| --- | --- | --- |
| `PrintSupport` | 桁架式支撐或輪廓邊接觸齒 | 封閉 Brep |
| `PrintGear` | 漸開線直齒輪，可調整尺寸與裝配間隙 | 封閉 Brep |
| `PrintThread` | 公螺紋、母螺紋或公母成對 | 封閉 Mesh |
| `PrintGridfinity` | 實體／鏤空母座與公座底板 | 封閉 Brep |
| `PrintSeamGroove` | 沿路徑建立三角截面溝槽刀具 | 封閉 Brep |

## 基本操作

在 Rhino 命令列輸入指令名稱，依繁體中文提示設定選項。Enter 確認或進入下一步，Esc 取消。主要建模參數會記錄於輸出物件的 User Text。

除 `PrintGridfinity` 固定以毫米輸入外，長度依目前文件單位輸入。以下尺寸範例以毫米為單位；`PrintSupport` 與 `PrintSeamGroove` 的首次預設尺寸會換算為文件單位。

## PrintSupport：列印支撐

### 三層設定流程

1. 輸入 `PrintSupport`，設定「列印噴頭尺寸」（預設 0.4 mm）與「列印層高尺寸」（預設 0.2 mm），按 Enter。
2. 選擇「桁架式支撐」或「輪廓邊接觸齒」。按 Enter 可沿用上次成功建立的類型。
3. 設定該類型的參數，按 Enter 後選取建模幾何。

成功建立的尺寸與支撐類型會在本次 Rhino 工作階段中保留。產生的支撐是獨立物件。

### 桁架式支撐

在量體表面指定一個接觸點，建立三根圓柱呈三角排列的鏤空支撐。柱間採單根斜撐，不使用 X 型交叉。

| 參數 | 預設值 | 用途 |
| --- | ---: | --- |
| 桁架寬度 | 10 mm | 頂部三柱的外接圓直徑，包含柱子半徑。 |
| 底部桁架寬度 | 0 | 0 表示與桁架寬度相同；非零值須介於桁架寬度與其三倍之間。 |
| 桿徑 | 0.8 mm | 主柱及斜撐的直徑。 |
| 尖端長度 | 3 mm | 接觸點到尖端圓錐根部的直線距離。 |

**使用步驟：**

1. 完成三層設定後，選取封閉 Brep 或擠出量體。
2. 在側面、下懸面或邊線上點選支撐接觸位置。
3. 檢查橘色預覽，可調整桁架參數，或選「重新選點」更換接觸位置。
4. 按 Enter 建立支撐。

**外形與尺寸：**

- 接觸端為直徑等於列印噴頭尺寸的半球，微量嵌入物件，並以漸粗過渡連接桁架。
- 柱間斜撐相對 World XY 水平面固定為 60°，自動安排分節；頂部不足完整一節的部分不建立斜撐。
- 尖端與頂部連接桿的軸線相對水平面至少為 60°。
- 底面對齊所選量體的最低 World Z，底板厚度為列印層高尺寸 × 3。
- 柱腳以高度 3 mm、底部直徑為桿徑 × 3 的圓錐台補強。
- 增大底部桁架寬度可讓支撐由下往上收攏。例如桁架寬度 10 mm，底部可設為 0 或 10–30 mm。

目前一次建立一個接觸點的支撐，支援封閉 Brep／擠出，不支援 Mesh、SubD 或 Block。空間不足、支撐穿入量體或接觸面方向不適合時會提示無有效預覽；可重新選點或調整寬度、桿徑及尖端長度。

### 輪廓邊接觸齒

由閉合輪廓建立板狀支撐，在指定邊段上均分接觸齒；接觸邊兩側收窄，減少與被支撐物的接觸範圍。

| 參數 | 預設值 | 用途 |
| --- | ---: | --- |
| 支撐厚度 | 2 mm | 支撐主體的厚度。 |
| 齒尖長 | 0.4 mm | 接觸齒沿 World XY 水平向外伸出的距離。 |
| 沿線齒尖數量均分 | 5 顆 | 總齒數，包含頭尾兩齒；可設 2–512 顆。 |

第一層的「列印噴頭尺寸」控制齒寬，「列印層高尺寸」控制 World Z 方向的齒高。

**使用步驟：**

1. 在接近垂直的平面畫出閉合支撐輪廓，例如三角形，讓接觸斜邊是一個可辨識的獨立邊段。必要時先 Split，再 Join 成閉合 PolyCurve。
2. 執行 `PrintSupport`，完成共用尺寸、支撐類型及接觸齒參數設定。
3. 選取閉合輪廓，再點選要長齒的邊段；候選邊會以紅色高亮。
4. 指令建立包含全部指定齒尖的封閉支撐，無須另選被支撐物件。

齒尖依可用邊長均分。三角形等尖角輪廓的頭尾齒會略向內退，直到可容納完整齒形，再於兩端有效位置間均分；不會省略齒尖或縮小齒形。

輪廓須為平面、閉合且不自交；接觸邊須沿 World Z 持續上升或下降，不能是水平邊或上下折返的邊。列印噴頭尺寸不得大於支撐厚度。若齒尖過密或輪廓太窄，請減少齒數、調整列印層高尺寸或加寬輪廓。

## PrintGear：漸開線直齒輪

1. 輸入 `PrintGear`。
2. 選擇尺寸模式，設定齒形、厚度與裝配參數。
3. 按 Enter，再指定齒輪底部中心點，建立封閉齒輪實體。

| 尺寸模式 | 使用方式 |
| --- | --- |
| 齒數與模數 | 直接指定齒數與模數。 |
| 目標含齒外徑 | 固定齒數，依目標外徑計算模數。 |
| 目標外徑（保持齒尺寸） | 保持模數，選擇最接近目標外徑的整數齒數；命令列會回報實際外徑。 |

| 參數 | 用途 |
| --- | --- |
| 齒數／模數 | 控制齒數與齒形大小；齒數範圍 6–500。 |
| 壓力角 | 控制齒形角度，範圍 14.5°–35°。 |
| 齒輪厚度 | 齒輪沿 Z 軸的厚度。 |
| 軸孔直徑 | 中央軸孔的標稱直徑。 |
| 背隙／齒側間隙 | 縮減齒厚與齒側，預留嚙合空間。 |
| 孔徑補償 | 加到標稱軸孔直徑的補償量。 |
| 輪轂直徑／輪轂厚度 | 設定中央輪轂；0 表示不建立，輪轂厚度不得大於齒輪厚度。 |

## PrintThread：公母螺紋

建立單線、截頂 60° 公制風格螺紋，可選公螺紋、母螺紋或公母成對。

1. 輸入 `PrintThread`，選擇類型並設定下列參數。
2. 按 Enter，再指定基準點。
3. 取得封閉網格；成對模式將公母件沿 X 方向並排，可用於裝配間隙試件。

| 參數 | 用途 |
| --- | --- |
| 公稱直徑 | 螺紋標稱外徑，例如 M20 輸入 20。 |
| 牙距 | 相鄰螺紋的軸向距離。 |
| 螺紋長度 | 有效螺紋長度；公件兩端加入短導入錐度。 |
| 單側間隙 | 母件內牙相對公件每側放大的尺寸。 |
| 母件壁厚 | 母件牙底外側的最小壁厚。 |
| 旋向 | 右牙或左牙。 |

可用 Rhino 的 Export 將結果匯出為 STL 或 3MF。

## PrintGridfinity：公母座方陣

建立 42 mm 格距的 Gridfinity 母座，以及同格數的一體式公座底板。所有尺寸選項均以毫米輸入。

1. 輸入 `PrintGridfinity`。
2. 選擇「只生成母座」、「只生成公座」或「公母成對」。
3. 設定母座類型、X／Y 格數、單側間隙及磁鐵孔加大量。
4. 按 Enter，指定底座左下角底部位置。底座平行 World XY；成對模式將公座放在母座右側。

| 參數 | 用途 |
| --- | --- |
| 母座類型 | 實體磁吸母座有底板及磁鐵孔；鏤空輕量母座無底板及母座磁鐵孔。 |
| X格數／Y格數 | 每邊 1–20 格，總格數不得超過 100。 |
| 單側間隙mm | 公母配合間隙，預設 0.25 mm，可設 0.10–0.40 mm。 |
| 磁鐵孔直徑加大量mm | 加到 6 mm 基準直徑的量，預設 0.5 mm，得到直徑 6.5 mm 的孔。 |
| 磁鐵孔深度加大量mm | 加到 2 mm 基準深度的量，預設 0.4 mm，得到深度 2.4 mm 的孔。 |

實體母座與公座每格各有四個磁鐵盲孔；鏤空母座不建立磁鐵孔。

## PrintSeamGroove：接縫溝槽刀具

沿曲線建立三角截面的獨立刀具，用來從構件扣除接縫集中槽。

1. 輸入 `PrintSeamGroove`，選取槽口中心線。可選曲線、PolyCurve 或可相接的線段／邊緣，按 Enter。
2. 選取參考面，讓尖端沿面的反法線切入；可用 Ctrl+Shift 選子面。也可直接 Enter 跳過選面，改以點選方式指定切入方向。
3. 檢查預覽並調整槽口寬度、槽深、外側延伸及尖端翻向。
4. 按 Enter 建立橘色封閉 Brep 刀具。
5. 執行 Rhino 的 `BooleanDifference`：先選被開槽的構件，再選刀具，完成開槽。

| 參數 | 用途 |
| --- | --- |
| 槽口寬度 | 三角槽在路徑位置的開口寬度。 |
| 槽深 | 從槽口向材料內部切入的深度。 |
| 外側延伸 | 刀具向材料外側延伸的量，方便穿過表面進行布林差集。 |
| 尖端翻向 | 反轉切入方向。 |
| 端部延長 | 延伸開放路徑兩端，僅手動方向模式提供。 |
| 截面旋轉角度 | 調整刀具截面的方向，僅手動方向模式提供。 |

支援平面或空間曲線，以及開放或封閉路徑。貼面模式要求路徑位於參考面上且切線連續；需處理折角時可使用手動方向模式。
