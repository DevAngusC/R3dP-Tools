# R3dP Tools

R3dP Tools 是一組為 Rhino 8 與 3D 列印工作流程設計的參數化建模工具，整合了輕觸式列印支撐、漸開線直齒輪與可列印公／母螺紋產生器。

Repository 名稱是 **R3dP Tools**；Rhino 內實際安裝的外掛檔名與產品名稱仍為 **Rhino3DPrintSupport**，既有指令名稱維持不變：

| Rhino 指令 | 帶來的功能 | 輸出 |
| --- | --- | --- |
| `PrintSupport` | 由閉合輪廓、接觸邊、接觸面或導引曲線建立低接觸面積、容易折除的 3D 列印支撐 | 封閉 Brep |
| `PrintGear` | 建立包含背隙、齒側間隙與孔徑補償的漸開線直齒輪 | 封閉 Brep |
| `PrintThread` | 建立可列印的公螺紋、母螺紋或公母公差測試對 | 封閉 Mesh |

三個工具都直接在 Rhino 命令列操作，使用繁體中文提示，並把主要製造參數寫入輸出物件的 User Text，方便後續檢查、匯出與重製。

建議在 Rhino 使用 **Millimeters** 作為模型單位。命令列顯示的數值均採用目前文件單位；`PrintSupport` 的首次預設值會從毫米自動換算。

## 系統需求

- Windows
- Rhino 8
- 從原始碼建置時需要 .NET 8 SDK
- Rhino 8 位於預設安裝位置；若位置不同，可在建置時覆寫 `RhinoSystemDir`

## 安裝

取得原始碼並建置：

```powershell
git clone https://github.com/DevAngusC/R3dP-Tools.git
cd .\R3dP-Tools
dotnet build .\PrintGear\PrintGear.csproj -c Release
```

在 Rhino 執行 `PlugInManager`，選擇 **Install**，載入：

```text
PrintGear\bin\Release\net8.0-windows\Rhino3DPrintSupport.rhp
```

若 Rhino 安裝在其他位置，可在建置時傳入：

```powershell
dotnet build .\PrintGear\PrintGear.csproj -c Release `
  -p:RhinoSystemDir="D:\Path\To\Rhino 8\System\netcore"
```

安裝後可直接在 Rhino 命令列執行 `PrintSupport`、`PrintGear` 或 `PrintThread`。如果 Rhino 已載入舊版外掛，請重新啟動 Rhino。

## PrintSupport：曲線驅動的輕觸式支撐

`PrintSupport` 參考[這段支撐設計影片](https://www.youtube.com/watch?v=1Zocl7n98xY&t=319s)中的側向穩定肋概念，用來建立接觸面積小、可正常切片且容易折除的列印支撐。它不是會自動分析所有懸垂面的切片器支撐系統。

工具提供 `輪廓邊接觸齒`、`自訂輪廓` 與 `導引曲線` 三種建立模式；支撐和模型維持為兩個拓撲上獨立的物件。

### 建議流程：輪廓邊接觸齒

1. 先把零件調整到實際列印方向。
2. 在一個近乎垂直的平面內畫出完整、閉合的支撐外形，例如三角形。把準備長出接觸齒的斜邊分成可辨識的獨立線段，並用 `Join` 保持整體為一條閉合 PolyCurve。
3. 執行 `PrintSupport`，使用預設的 `建立模式=輪廓邊接觸齒`，設定 `支撐厚度`、`齒尖線寬XY`、`齒水平伸長XY`、`齒高度Z` 與 `沿線齒距`。
4. 選取閉合支撐輪廓，接著在要長出細小接觸齒的邊段中央點一下；游標下的候選邊會以紅色高亮。
5. 外掛會先把完整輪廓擠出為 `支撐厚度`，再對所選接觸邊位於主體前、後側的兩條長邊一次執行連續 45° Chamfer；接著沿接觸線實際長度陣列固定尺寸的貼邊方塊齒。每顆齒會截取一小段接觸線並沿 World XY 水平向外平移，因此根部完整貼合斜邊或曲邊、上下端保持 World XY，厚度則是 `齒尖線寬XY`。最後將主體與接觸齒合併成獨立封閉 Brep。此流程完全不需要選取目標模型或接觸面。

### 進階流程：自訂輪廓

1. 執行 `ExtractSrf`，把 `Copy` 設為 `Yes`，複製出真正需要支撐的單一接觸面。
2. 畫出閉合平面支撐外形，讓輪廓完整跨過複製面的剖線，並只穿入接觸面一小段。
3. 執行 `PrintSupport`，選擇 `建立模式=自訂輪廓`。先選複製面，再選閉合輪廓。
4. 也可以直接選取完整模型；多重曲面、擠出、Mesh、SubD 與 Block 的原有流程仍然保留。

兩種閉合輪廓模式都不使用 `平台高度` 或 `底腳延伸`。產生的 `PrintSupport_LightTouch_*` 是獨立封閉 Brep；不要與模型做布林聯集。

`建立模式=導引曲線` 保留原本流程：選取模型接觸邊界的開放、垂直共平面曲線，由外掛向指定 World Z 平台自動補出支撐底部。這個舊模式才會使用 `平台高度` 與 `底腳延伸`。

| 選項 | 預設（毫米模型） | 說明 |
| --- | ---: | --- |
| `建立模式` | 輪廓邊接觸齒 | `輪廓邊接觸齒` 不需要模型；`自訂輪廓` 由接觸面與閉合造型推導接觸線；`導引曲線` 是原本的 World-Z 模式。 |
| `支撐厚度` | 2.00 mm | 支撐主體在剖面法向的厚度。 |
| `齒尖線寬XY` | 0.40 mm | 僅用於 `輪廓邊接觸齒`。它同時是連續 Chamfer 後中央脊線的寬度，以及每顆貼邊方塊齒在支撐厚度方向的寬度。建議填入切片器的一道實際列印線寬。 |
| `齒水平伸長XY`／`接觸退讓` | 0.25 mm | `輪廓邊接觸齒` 中代表接觸線片段沿 World XY 水平向外平移的可見距離；其他模式代表主肋退讓距離。 |
| `齒高度Z`／`接觸齒寬` | 0.40 mm | `輪廓邊接觸齒` 採真正的 World Z 方塊高度；其他模式採沿接觸線的齒寬。 |
| `沿線齒距`／`接觸齒間距` | 5.00 mm | `輪廓邊接觸齒` 採沿所選接觸線實際長度的中心距；其他模式也採沿接觸線的中心距。 |
| `底腳延伸` | 2.00 mm | 僅供 `導引曲線` 模式使用。 |
| `平台高度` | 0.00 | 僅供 `導引曲線` 模式使用，代表列印平台的 World Z。 |

影片只明確展示 0.25 mm 主肋退距；齒尖線寬、齒寬、齒距與肋厚是此外掛提供的可調起始值，不是影片宣稱的固定規格。0.40 mm 是常見起點，實際應填入切片器的外牆線寬，例如 0.42 或 0.45 mm。`齒尖線寬XY=支撐厚度` 代表不收尖，可重現原本的等厚接觸齒。

主體的筆尖造型直接重現手工 `ChamferEdge` 流程。令 `T=支撐厚度`、`W=齒尖線寬XY`，前後兩條接觸邊的 Chamfer 距離皆為 `C=(T-W)/2`。例如 `T=2、W=0.4 mm` 時，`C=0.8 mm`；兩側 45° 斜面沿整條接觸邊連續建立，中央留下 `0.4 mm` 寬的平面脊線。`T=3、W=0.4 mm` 時，Chamfer 距離為 `1.3 mm`。

貼邊方塊齒的尺寸仍是 `W=齒尖線寬XY`、`H=齒高度Z`、`D=齒水平伸長XY`，但不再以單一中心點放置軸向 Box。程式會用 `中心Z±H/2` 截取接觸線片段，把整段水平向外平移 `D` 後封閉成齒面；所以直斜邊的側視輪廓是完整平行四邊形，曲邊則是等距帶狀輪廓，不會被斜主體吃掉一角。根部會在主體內藏入一個很小的容差重疊以提高 Boolean 穩定性，但可見外伸仍精確停在 `D`。目前預設 `W×H×D=0.4×0.4×0.25 mm`、`沿線齒距=5 mm`；`0.4×0.2×0.3 mm` 則是手工流程的參考尺寸。

貼邊方塊齒先批次與 Chamfer 主體合併；批次失敗時改為逐顆合併，單顆仍失敗才略過。命令列與物件 User Text 會記錄 Chamfer 距離、接觸齒數量與略過數量。至少要有一顆接觸齒成功才會輸出，不會把只有主體的物件當成完整支撐。

### 目前限制

- `輪廓邊接觸齒` 要求單一閉合、近乎垂直且不自交的平面 PolyCurve；所選邊段必須沿 World Z 單調變化，並能以單一 World XY 水平方向判定外側。水平、上下折返或外側方向反轉的邊段會被拒絕，必要時請先 `Split` 成較短邊段。
- `齒尖線寬XY` 不得大於 `支撐厚度`。切片前應確認齒尖仍被辨識為單道可列印路徑，而不是消失或被切片器擴成多道線。
- 連續 Chamfer 必須能在接觸邊兩端及輪廓內側容納 `C=(支撐厚度-齒尖線寬XY)/2`。若輪廓局部比此距離更窄，應縮短接觸段、增加齒尖線寬或加寬支撐輪廓；外掛不會偷偷退回舊的逐齒斜面。
- `沿線齒距` 是沿接觸曲線量測，不是 World Z 高度差；貼邊方塊齒本身的頂底仍保持固定 World Z。
- 若閉合輪廓只有一個平滑段（例如未分割的圓或封閉 NURBS），請先在接觸區兩端 `Split`，再 `Join` 成含有獨立邊段的 PolyCurve。
- `自訂輪廓` 必須是單一閉合、平面且不自交的曲線；使用複製接觸面時，輪廓必須完整跨過面剖線並形成至少兩個交點，而不是只相切。
- 建議每次選一個由 `ExtractSrf Copy=Yes` 取得的單一接觸面。若接觸面把輪廓切成多個區域，目前保留面積最大的一塊；因此只應穿入接觸面一小段。
- 完整模型流程仍支援多重曲面、擠出、Mesh、SubD 與 Block；完整模型剖面必須能形成閉合迴圈。非平面支撐外形尚未支援。
- 若模型把一個輪廓切成多塊，目前只保留面積最大的一塊並顯示警告。
- `導引曲線` 模式仍要求開放、近似垂直共平面，且沿平台方向不可反折。
- 尚未自動分析懸垂角；曲面在支撐厚度方向變化很大時，仍應在切片前檢查碰撞與外周路徑。
- 0.25 mm 是影片中的成功起點，不是所有材料、層高與噴嘴的固定答案；請先做短件測試並檢查切片路徑。

## PrintThread：可列印公／母螺紋

在 Rhino 命令列輸入 `PrintThread`，設定參數後按 Enter，再選擇基準點。工具會建立單線、截頂 60° 公制風格螺紋；可產生公螺紋、母螺紋，或沿 X 軸並排的公母公差測試對。

| 選項 | 說明 |
| --- | --- |
| `類型` | `公螺紋`、`母螺紋` 或 `公母成對`。成對模式會在 X 方向把兩件並排產生。 |
| `公稱直徑` | 公稱外徑（例如 M20 輸入 `20`）。 |
| `牙距` | 單線、60° 公制風格螺紋的牙距。 |
| `螺紋長度` | 螺紋有效長度。公件兩端會自動加入短導入錐度。 |
| `單側間隙` | 單側間隙；母件內牙會比公件每側放大此數值。 |
| `母件壁厚` | 母件在牙底之外的最小壁厚。 |
| `旋向` | `右牙`（預設）或 `左牙`。 |

產生的物件是封閉網格（closed mesh），適合直接用 Rhino 的 `Export` 匯出 STL 或 3MF。物件也會寫入 User Text 保存主要製造參數。

### 3D 列印起始設定

| 製程 | `RadialClearance`（每側） | 建議 |
| --- | ---: | --- |
| FDM | 0.15–0.30 mm | 先用 0.20 mm；高流量或粗噴嘴可增加。 |
| 樹脂 | 0.05–0.15 mm | 先用 0.10 mm，依後固化收縮調整。 |

為確認機台公差，建議先用 `公母成對` 做短件試印，再把相同牙距與單側間隙用到正式零件。母件的壁厚至少應為 `0.45 × 牙距`；實務上 2–3 mm 以上較耐用。

## PrintGear：漸開線直齒輪

`PrintGear` 可產生適合 3D 列印與公差測試的漸開線直齒輪。設定參數後按 Enter，再選擇齒輪底部中心點；工具會輸出封閉 Brep，並保存主要參數至 User Text。

| 選項 | 預設值 | 說明 |
| --- | ---: | --- |
| `齒數` | 24 | 支援 6–500 齒。 |
| `模數` | 2.0 | 控制齒輪整體尺寸與齒距。 |
| `壓力角` | 20° | 支援 14.5°–35°。 |
| `齒輪厚度` | 8.0 | 沿 Z 軸擠出的實體厚度。 |
| `軸孔直徑` | 5.0 | 中央軸孔的標稱直徑。 |
| `背隙` | 0.15 | 從齒厚扣除的圓周背隙。 |
| `齒側間隙` | 0.05 | 額外縮減齒側以增加列印裝配空間。 |
| `孔徑補償` | 0.20 | 加到標稱軸孔直徑，用來補償列印後孔徑偏小。 |
| `輪轂直徑` | 0 | 可選中央輪轂；0 代表不建立。 |
| `輪轂厚度` | 0 | 可選輪轂厚度，不得大於齒輪厚度。 |
